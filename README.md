# Онлайн-бронирование столиков в ресторане

Веб-приложение для бронирования столиков в ресторане, выполненное на Next.js и TypeScript.

## Функционал

* Форма бронирования с валидацией полей:
  * Имя (обязательное поле, от 2 символов)
  * Телефон (маска `+7 (XXX) XXX-XX-XX`, проверка полного номера)
  * Количество гостей (выбор из списка)
  * Дата (выбор даты, начиная с сегодняшней, по локальному времени)
  * Время (выбор из доступных слотов; время, которое уже прошло, выбрать нельзя)
  * Чекбокс «С политикой конфиденциальности ознакомлен» (обязательный)
* Подсветка ошибок и вывод сообщений при невалидном вводе.
* SVG-иконки в полях формы (без внешних библиотек).
* Кастомный селект (`CustomSelect`) для выбора гостей и времени, чтобы реализовать скролл меню выбора. Поддерживает управление с клавиатуры (стрелки, Home/End, Enter/Space, Escape).
* Экран подтверждения с итоговыми данными после успешной отправки.
* Плавная анимация появления формы и экрана подтверждения (отключается при `prefers-reduced-motion`).
* Возможность сбросить форму и сделать новое бронирование.
* Состояние загрузки (имитация отправки на сервер, 1,5 с).
* Доступность: подписи к полям, `aria-invalid` / `aria-describedby` для ошибок, корректные роли в `CustomSelect`.

## Стек технологий

* React / Next.js (Pages Router)
* TypeScript
* SCSS (CSS Modules)

## Структура проекта

Проект организован по архитектуре FSD (Feature-Sliced Design):

```
src/
├── features/
│   └── booking/
│       ├── model/        # types, validation, dateUtils, useBookingForm
│       └── ui/           # BookingForm, ConfirmationScreen
├── shared/
│   ├── config/           # constants (слоты времени, варианты гостей, ссылка на политику)
│   ├── lib/              # phoneMask
│   └── ui/               # CustomSelect, icons
├── pages/                # страницы приложения
└── styles/               # глобальные стили и CSS-переменные
```

## Что можно улучшить дальше

1. Заменить заглушку `PRIVACY_POLICY_URL` в `shared/config/constants.ts` на реальную страницу политики.
2. Подключить настоящий API вместо имитации отправки.
3. Покрыть тестами `validation.ts`, `dateUtils.ts` и `phoneMask.ts`.

## Установка и запуск

1. Клонировать репозиторий:

```
git clone https://github.com/stephcurry270/booking-restaurant.git
```

2. Установить зависимости:

```
npm install
```

3. Запустить проект в режиме разработки:

```
npm run dev
```

Приложение будет доступно по адресу: http://localhost:3000

Сборка для продакшена:

```
npm run build
npm run start
```
